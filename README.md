# DentCare — Стоматологическая клиника

Учебный проект по дисциплине **Фронтенд-разработка**.  
Тема №01: Стоматологическая клиника.

## Стек технологий

- React 18 + React Router v6
- React Bootstrap 2.x + Bootstrap 5
- react-slick (слайдеры)
- Formik + Yup (форма с валидацией)
- Leaflet + react-leaflet (карта)
- react-qr-code (QR-код)
- react-icons (иконки)

## Структура страниц

| Маршрут | Страница |
|---------|----------|
| `/` | Главная |
| `/about` | О нас |
| `/services` | Услуги |
| `/contacts` | Контакты |
| `*` | 404 |

## Функциональность

- ✅ Hero-слайдер с автопрокруткой (react-slick)
- ✅ Блок преимуществ, услуг, врачей, отзывов
- ✅ Фильтрация услуг по категориям (без перезагрузки)
- ✅ Форма записи с полной валидацией (Formik + Yup)
- ✅ Встроенная карта Leaflet с маршрутом и маркерами
- ✅ QR-код с возможностью скачать в PNG
- ✅ Адаптивность на всех брейкпоинтах
- ✅ Sticky Navbar с hamburger-меню на мобильных
- ✅ 404 страница

## Запуск проекта

```bash
npm install
npm start
```

## Деплой на GitHub Pages

1. Поменяйте `homepage` в `package.json` на ваш репозиторий
2. В `App.jsx` измените `basename="/"` на `basename="/dental-clinic-react"`

```bash
npm run deploy
```

## Деплой на Vercel

Подключите GitHub репозиторий через [vercel.com](https://vercel.com) — деплой автоматический.
